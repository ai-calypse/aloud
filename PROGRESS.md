## ✅ Phase 0 — Scaffold (commit `d1aad5b`, local only)

Toolchain installed from scratch (neither was present):
- Rust 1.97.1 via rustup + clippy/rustfmt components
- pnpm 11.13.1 via corepack

**Structure** (lean, per the plan — not anarlog's 150-crate monorepo):
```
Cargo.toml              workspace: apps/desktop/src-tauri + crates/*
pnpm-workspace.yaml     workspace: apps/*
apps/desktop/           Tauri v2 + Vite + React 19 + TS
  src-tauri/src/
    main.rs             thin entry, windows_subsystem guard for release
    lib.rs              builder, specta bindings export, tracing
    tray.rs             tray icon + menu
  src/lib/bindings.ts   GENERATED by tauri-specta — do not hand-edit
crates/notes/           port of NotesStore.swift
```

**Decisions made:**
- **Dependency versions pinned from crates.io as of today**, not from
  memory: `specta`/`tauri-specta` `=2.0.0-rc.25` (exact-pinned; they're RCs
  and move in lockstep — a floating minor would break the build).
  Verified available: cpal 0.18.1, whisper-rs 0.16.0, arboard 3.6.1,
  enigo 0.6.1, rusqlite 0.40.1, reqwest 0.13.4, xcap 0.9.6, rodio 0.22.2.
- **`specta` centralized in `[workspace.dependencies]`** with the `derive`
  feature — first build failed without it (`cannot find Type in specta`).
- **Menu-bar only**: `ActivationPolicy::Accessory` on macOS, main window
  starts `visible: false`. Matches the Swift app's `LSUIElement` behavior.
- **CSP is set**, not `null` as the scaffold ships it. No reason to run
  a local-only app with CSP disabled.
- **Bundle targets**: `dmg`/`app` (mac) + `nsis` (Windows).
  Identifier `app.aloud.desktop`, min macOS 13.0 — matches the Swift app.
- **Bindings regenerate on every debug run** so the frontend can't drift
  from the Rust command surface. Note: they're emitted relative to the
  crate dir, so the app must be run from `apps/desktop/src-tauri`
  (or via `pnpm tauri dev`, which handles cwd correctly).

**`crates/notes`** — port of `NotesStore.swift`:
- Identical search semantics: all query terms must match, title hits
  weighted 10x, ~160-char snippet around first body match.
- **All 7 Swift test cases ported to Rust and passing**, same inputs and
  expectations — a real regression guard, since this logic is user-visible.
- **2 new tests** beyond the Swift original: filename collision handling,
  and path-separator sanitization (`1/2 sync: recap` would produce an
  invalid filename on Windows — the Swift version never had to care).
- Snippet slicing is char-based, not byte-based; the Swift version used
  `String.Index` which is inherently char-safe. A naive byte port would
  panic on any non-ASCII note.

**Verified:** `cargo test` 9/9 pass · `cargo clippy` clean · `tsc --noEmit`
clean · `cargo build -p aloud` succeeds · bindings.ts generates correctly.
