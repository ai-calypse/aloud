# references

Source material for the website. Anything already optimized for the site lives in
`src/assets/` and its original was deleted from here, so what is left is only
unused material (kept for later).

- `memes/`: standalone meme images not on the site yet
- `ui/`: UI inspiration screenshots
- `cats/`: cat and character stickers, grouped by mood
  (`working/`, `reactions/`, `money/`, `errors/`, `characters/`, `misc/`)
