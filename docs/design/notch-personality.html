Palette

Values are read from the CarPlay Design System Figma file (see docs/design/figma-carplay-index.md): Music #FF4F65, Fitness Move #F9104F, Calendar red #FF4539, Batteries green #34C85A, Maps blue #0A84FF, Podcasts #C340FF, Screen Time cyan #3FC7DF. Each is written in OKLCH with the hex as the fallback and measured against the tile (#1C1C1E). Fills and rings clear 3:1 everywhere; text clears AA, tinted toward white where the Figma colour alone is under 4.5:1. Only the agent indigo is not in the file. Roles are meaning, not decoration: pink is music, a draining red ring is time.

Components

All of it is inline SVG and CSS. The numerals roll, the rings fill on a spring, the bars run on the compositor.

Build notes

Mapping onto the codebase

  • Roles become --notch-accent-media|time|today|ok|caution|alert|info|clip|net|agent beside the existing --notch-ok|warn|danger (those three alias caution, alert, ok). Add OKLCH values with the hex fallbacks in tokens.css, then expose each through @theme inline and the cn() tailwind-merge list, or text-time will fight text-ui.
  • New primitives in components/notch/: Tile (size prop, --acc from a role prop), Gauge (Ring, SegBar, Capsule as variants), Numeral (digit roller), Chip. Ring reuses lib/spring.ts.
  • "Calm" is the existing Mix with the accent switch off: --acc: var(--notch-ink). Ship it as a Settings choice and delete nothing.
  • Home replaces views/Now.tsx; its tile list ranks d.islands the same way the pill does.

Risks

  • Contrast: the Figma reds, blue and purple are 4.2 to 5:1 on #1C1C1E, so words use --acc-ink (68% toward white); rings and fills only need 3:1. Deep live tiles lower ink-2, so it is lightened inside them. Three reds (Music, Move, Calendar) plus system red sit close; the strip tells them apart by position and word, but a colour-blind reader leans on the word.
  • Motion cost: five rings can be live at once (tile, pill, drop chip). Rings are one SVG circle; the drain is a 1s CSS transition and springs run only on a jump, so the idle cost is the digit roller and bars. Cap at four rolling numerals.
  • 780px: the 8x3 grid leaves 85px 1x1 tiles; a 20pt numeral is the most they hold. Anything denser stays in its section.
  • Packing: the ranker is brute-force over size options; with more tiles it needs a real solver, or fixed layouts per count.

What I would not do

  • Source: CarPlay Design System (Figma community file kLPrZ1jNJLJzH6ZpqQY7rz), indexed in docs/design/figma-carplay-index.md: tiles #1C1C1E and #252525, Light numerals at 32 to 45pt, the ring-over-same-hue-track pattern, and the gauge rule (deepest shade for the tile, lightest tint for ring and numerals), which is what a live tile does here.
  • No glow on rings, no gradient fills, no blur behind tiles. The tinted media tile is a flat mix of the art colour into the tile.
  • No per-tile icons in the tab strip, no tile for every feature. Home shows what is live; the rest is one tab away.
  • No red as a section colour: red means alert, and always arrives with a word.
  • Do not animate tile sizes with scale; position reflows by FLIP, content crossfades.
